## Phase Goal

**As a** child who finished the math question, **I want to** throw with a timing bar and catch the Pokémon (or see it flee kindly after three tries), **so that** commons feel easy to catch and legendaries stay exciting.

**This plan's slice:** first end-to-end catchable path — education feedback → timing → grade flash → shake → Caught card → Continue. Retry/flee remain stubs/deferred to `05-04`; timing ping-pong polish lands in `05-03`.

**Scope note:** This plan intentionally touches ~11 files as one vertical MVP slice (types → store → flow → overlay UI). Store/flow and UI stay together so a player can catch after a single plan; do not split unless executor context pressure appears.
