## Spacing Scale

Declared values (must be multiples of 4) — **same as Phase 1**:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Pixel inset inside D-pad arms, tile seam hairlines |
| sm | 8px | Gap between D-pad arms and center dead zone |
| md | 16px | Default padding; map viewport edge inset from shell |
| lg | 24px | Gap between map bottom edge and D-pad cluster |
| xl | 32px | Desktop side breathing room inside 480px column |
| 2xl | 48px | Reserved clearance above BottomNav (shell already uses ~4.5rem + safe-area) |
| 3xl | 64px | D-pad direction hit target size (see exceptions) |

Exceptions:
- **D-pad direction hit targets:** **64×64px** minimum each (Up / Down / Left / Right). Exceeds Phase 1 chrome 48px and the Phase 1 research floor (≥60px) for a ~7-year-old. **Discretionary default.**
- **D-pad cluster footprint:** outer bounding box **192×192px** (3×64 cross) with **8px** arm gap to an inactive center cell (non-interactive).
- **Safe areas:** D-pad sits above BottomNav; bottom offset = `calc(4.5rem + env(safe-area-inset-bottom) + 16px)` from viewport bottom. Left inset = `max(16px, env(safe-area-inset-left))`. Right side of Game screen stays clear for future HUD (no mirror D-pad).
- **Touch chrome (BottomNav):** unchanged — `.touch-target` 48×48 min / preferred 56×56.

### Map tile palette (Forest — discretionary defaults)

| Tile role | Hex | Visual rule |
|-----------|-----|-------------|
| Ground / path | `#C8E6A0` | Walkable floor; lighter meadow green (matches Home meadow end-stop) |
| Grass (encounter tile) | `#3D8B4F` | **Visually distinct** denser green with subtle darker stipple / taller pixel blades; must read as “tall grass” at a glance vs ground |
| Obstacle (tree / rock) | `#1F5A36` canopy + `#6B4A2E` trunk/rock | Blocked; silhouette taller than ground; never same fill as grass |
| Water / void (map edge letterbox) | `#E3F2C9` | Shell dominant — no fake water biome in Phase 3 |
| Player outline | `#1A3324` | 1px pixel outline so sprite reads on grass and ground |

Accent reserved for (Phase 3 additions bolded):
1. Primary CTA fill (“Start Safari”) — Home only
2. Active bottom-nav indicator
3. Focus ring (`outline: 3px solid #E8B923`) — including D-pad when focused via keyboard/tab if focusable
4. Home brand sun-dot
5. **D-pad pressed / active direction fill** (held pointer or key) — swap arm from secondary to accent while held
6. **Optional DEV-only grass-event debug pip** — never in production UI

Never use accent for: tile fills, camera chrome, body text, large map backgrounds, inactive D-pad arms.

## Screen Inventory & Layout

### Game screen (`/game`) — Phase 3 focal surface

Replace Phase 1 `EmptyState` placeholder with explore composition inside existing `AppShell` (max-width **480px**, BottomNav fixed).

```
┌─────────────────────────────┐  ← AppShell column (≤480px)
│ Forest                      │  ← optional 32px top strip, Label 14px
├─────────────────────────────┤
│                             │
│      MAP VIEWPORT           │  ← flex-1; overflow:hidden; touch-action:none
│   (player visually centered)│
│                             │
│  ┌─────┐                    │
│  │ D-PAD│                   │  ← overlay, bottom-left above nav
│  └─────┘                    │
├─────────────────────────────┤
│  Home Game Dex Pack Settings│  ← BottomNav (unchanged)
└─────────────────────────────┘
```

**Layout rules:**
1. **One composition:** map viewport is the hero plane; D-pad is the only chrome overlay; no cards, stat strips, or encounter banners.
2. **Map viewport:** fills all space between optional biome strip and the D-pad clearance zone; `overflow: hidden`; background `#E3F2C9`.
3. **World layer:** CSS-transformed tile world (RESEARCH Pattern 1); player sprite drawn centered in the viewport (camera math moves the world, not the player DOM position off-center).
4. **D-pad placement:** bottom-left overlay, never overlapping BottomNav hit areas; never covering more than ~35% of viewport height.
5. **Top bar:** thin biome label only — **omit** Phase 1 centered `ScreenTitle` “Game” + EmptyState. BottomNav already labels the route.
6. **Desktop (≥768px):** same single column (`mx-auto max-w-[480px]`); **D-pad remains visible** (discretionary default — tablets / kid-on-laptop / discoverability). Keyboard (arrows/WASD) is primary on desktop but does not hide touch controls. Do not switch to a multi-column dashboard or side panel map.

### Other routes

Home / Dex / Pack / Settings: **no Phase 3 visual changes** except Start Safari continues to land on playable `/game`.

## Tile & Rendering Contract

| Property | Value | Source |
|----------|-------|--------|
| Source tile size | **16×16 px** | Discretionary (RESEARCH A2) |
| Display scale | **3×** integer only | → **48×48 CSS px** per tile |
| Map size (Forest) | **20×15** tiles | Discretionary (RESEARCH) |
| Render approach | CSS world `transform: translate3d(...)` + img/div tiles | RESEARCH primary; Canvas deferred |
| Scaling filter | `.pixelated` (`image-rendering: pixelated` + `crisp-edges`) | Phase 1 utility |
| Non-integer scales | **Forbidden** on tile/player images | Avoid retina blur |
| Grass distinctness | Different base hex + stipple/blade pattern vs ground | MAP-02 + CONTEXT |
| Obstacles | Collision layer opaque visually (trees/rocks) | CONTEXT |

**Player sprite presentation:**
- Placeholder 16×16 (or 16×24) pixel character; scale **3×** → 48×48 (or 48×72) CSS px.
- Four facings: up / down / left / right.
- Walk cycle: **2–4 frames** per facing; advance frame every **100ms** while a step tween is active (**discretionary**).
- Idle: first frame of current facing; turn-in-place updates facing without tween.
- Always `.pixelated`; 1px `#1A3324` outline recommended for contrast on grass.

| Property | Value | Source |
|----------|-------|--------|
| Follow mode | Player stays visually centered; world scrolls beneath | CONTEXT locked |
| Smoothing | Exponential ease toward target; stiffness **12** | Discretionary (RESEARCH A4) |

| Reduced motion | See Accessibility — camera snaps (stiffness effectively infinite / follow = 1) | Discretionary |

## D-Pad Visual & Interaction Spec

### Visual

| Property | Value |
|----------|-------|
| Shape | Plus / cross (4 arms); square arms with **4px** radius; hard pixel shadow `2px 2px 0 #1A3324` (not blur) |
| Default fill | Secondary `#2F7A4B` |
| Chevron / arrow | `#F5FBEF`, 24×24 inline SVG, `aria-hidden` |
| Pressed / held fill | Accent `#E8B923`; chevron `#1A3324` |
| Disabled / center | Muted `#6B8F6E` at 40% opacity; not a button |
| Hit target per arm | **64×64px** minimum |
| Opacity | **100%** on mobile; on desktop (≥768px) keep **100%** (do not fade — kids need clear affordance) |

### Interaction

| Input | Behavior |
|-------|----------|
| `pointerdown` on arm | Add direction to shared held set; show pressed style |
| `pointerup` / `pointerleave` / `pointercancel` / `lostpointercapture` | Remove that direction; clear pressed style |
| Multi-touch | Last-in or priority stack OK; document single primary direction via `primaryDirection(held)` |
| Keyboard | Arrow keys + WASD → **same** held set (MAP-01); physical key does not require focusing D-pad |
| Scroll / zoom steal | `touch-action: none` on MapViewport **and** DPad root; `user-select: none`; non-passive `touchmove`/`touchstart` `preventDefault` **scoped to those nodes only** |
| BottomNav conflict | D-pad never overlaps nav; pointer events on D-pad must not activate nav links |

### Motion (intentional — Phase 3)

1. **D-pad press:** 80ms scale to **0.96** on the active arm, release spring back (match Phase 1 CTA press language).
2. **Walk step:** 200ms world/player lerp between tiles.
3. **Camera ease:** continuous exponential follow while moving (not a bounce loop).

No continuous idle bob on player; no glow pulses; no encounter flash.

## Accessibility

- D-pad: `role="group"` with `aria-label="Walk controls"`; each arm `<button type="button">` with `aria-label` Move up/down/left/right.
- Icon SVGs inside arms: `aria-hidden="true"`.
- Keyboard parity: arrows/WASD work without focusing the D-pad; document in UI that both work (no on-screen legend required in Phase 3).
- Contrast: `#F5FBEF` on `#2F7A4B` and `#1A3324` on `#E8B923` (pressed) meet WCAG AA for UI controls.
- Do not rely on color alone for grass — add stipple/blade pattern so grass ≠ ground for color-vision differences.
- Map viewport: not a focus trap; Tab still reaches BottomNav.

### Reduced motion (`prefers-reduced-motion: reduce`)

| Effect | Behavior under reduced motion |
|--------|-------------------------------|
| Camera ease | **Snap** camera to follow target each frame (no lag) |
| Walk cycle frames | **Freeze** on facing frame 0 (no frame animation) |
| Step position tween | **Snap** to destination tile (0ms visual lerp) — gameplay position still updates one tile at a time |
| D-pad press scale | Instant pressed style; skip 80ms scale animation |
| Phase 1 nav/CTA motions | Already skipped via existing global reduced-motion CSS |

Gameplay (collision, grass events, shared input) remains fully functional.
