# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual) |
| Preset | not applicable |
| Component library | none — hand-rolled React + Tailwind v4 utilities |
| Icon library | Inline SVG icons (hand-authored, 24×24 viewBox, 2px stroke) — no Lucide/Heroicons dependency in Phase 1 |
| Font | **Pixelify Sans** (display + headings) + **Fredoka** (body + labels) via Google Fonts |

**Manual design system:** CSS custom properties in `src/index.css` under `@theme` (Tailwind v4) plus utility classes `.pixelated`, `.pixel-border`, `.touch-target`. No shadcn — greenfield Vite app; YOLO decision to skip shadcn init for a lightweight pixel-game shell.

**Anti-patterns (forbidden):**
- Purple-on-white / purple-to-indigo gradient themes
- Warm cream `#F4F1EA` + terracotta accent pairing
- Dark-mode-by-default (light outdoor daylight only for v1 shell)
- Glow / neon / multi-layer soft shadows
- `rounded-full` pill chips for nav or CTAs (use 4–8px radius max)

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, hairline inset inside pixel borders |
| sm | 8px | Compact element spacing, label-to-icon gap |
| md | 16px | Default element spacing, screen content padding (mobile) |
| lg | 24px | Section padding, stack gaps between placeholder blocks |
| xl | 32px | Layout gaps, desktop content padding |
| 2xl | 48px | Major section breaks, safe inset above bottom nav |
| 3xl | 64px | Page-level top/bottom breathing room on Home hero |

Exceptions:
- **Touch targets:** minimum **48×48px** hit area for all chrome controls; preferred **56×56px** for bottom-nav icons (UX-01 / kid ~7yo). Not a spacing-token step — apply via `.touch-target` min-width/min-height.
- **Future D-pad (Phase 3, not built here):** research floor ≥60px — document only; do not implement in Phase 1.
- **Safe areas:** pad bottom chrome with `env(safe-area-inset-bottom)` added to the 48px nav stack gap.

---

## Typography

Exactly 4 sizes, exactly 2 weights.

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Label | 14px | 400 | 1.4 | Fredoka |
| Body | 16px | 400 | 1.5 | Fredoka |
| Heading | 22px | 700 | 1.2 | Pixelify Sans |
| Display | 32px | 700 | 1.15 | Pixelify Sans |

Weights allowed: **400** (regular) and **700** (bold) only. Do not introduce 500/600.

**Letter-spacing:** Display/Heading +0.02em for pixel font readability; Body/Label 0.

**Loading:** `@import` or `<link>` Google Fonts with `display=swap`. Fallback stack: `Pixelify Sans, "Courier New", monospace` / `Fredoka, "Trebuchet MS", sans-serif`.

## Color

60 / 30 / 10 split — Emerald grass, warm outdoor daylight (not cream/terracotta, not purple, not dark-first).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#E3F2C9` | App background, screen surfaces, Home meadow wash |
| Secondary (30%) | `#2F7A4B` | Bottom nav bar, top app bar, panel fills, pixel-border frames |
| Accent (10%) | `#E8B923` | Reserved elements only (see list below) |
| Destructive | `#C45C4A` | Destructive actions only (Settings stub “Reset Save” confirm) |
| Text primary | `#1A3324` | Body and headings on dominant surfaces |
| Text on secondary | `#F5FBEF` | Labels/icons on emerald chrome |
| Muted / placeholder | `#6B8F6E` | Placeholder screen helper text, inactive nav icons |

Accent reserved for:
1. Primary CTA fill (“Start Safari”)
2. Active bottom-nav indicator (underline bar or filled icon state)
3. Focus ring (`outline: 3px solid #E8B923`) on keyboard focus
4. Home brand sun-dot / decorative accent mark next to title (≤16×16)

Never use accent for: body text, large background fills, inactive icons, borders of every panel, or placeholder cards.

**Atmosphere (not a second accent):** subtle vertical gradient on Home only — `#E3F2C9` → `#C8E6A0` (field green deepen). No images required in Phase 1; gradient + pixel pattern utility is the visual plane.

## Screen Inventory & Layout

Phase 1 routes (React Router `basename: '/pokemon-safari'`):

| Route | Screen | Purpose |
|-------|--------|---------|
| `/` | Home | Brand hero + primary CTA |
| `/game` | Game | Placeholder for explore (no map yet) |
| `/dex` | Pokédex | Placeholder |
| `/pack` | Inventory | Placeholder (“Pack” in chrome) |
| `/settings` | Settings | Placeholder + optional Reset Save stub UI (no persist wiring) |

### Shell chrome

- **Bottom nav** (mobile-first, always visible on placeholder screens): 5 icon+label items, secondary fill `#2F7A4B`, active item uses accent indicator.
- **Top bar:** optional short title of current screen (Heading 22px / 700) on non-Home routes; Home omits top bar so brand can own the viewport.
- **Desktop (≥768px):** same bottom nav centered in a max-width **480px** column (`mx-auto`); do not switch to a multi-column dashboard.

### Home — first viewport (one composition)

Focal point order (eye path):
1. **Brand** — “Pokémon Safari” Display 32px / 700 (must dominate; no larger competing headline)
2. One supporting sentence (Body 16px): **Walk the grass. Meet Pokémon. Fill your Pokédex.**
3. Primary CTA **Start Safari** → navigates to `/game`
4. Atmosphere: meadow gradient + optional 8px pixel-grid pattern (CSS only)

Do **not** put stats, schedules, address blocks, or secondary marketing in the first viewport.

### Placeholder screens

Single purpose each: Heading + empty-state copy centered above bottom nav. No cards required — plain stacked text on dominant surface inside a secondary pixel-border frame (8px padding inside border).

### Root `index.html` listing

Simple project list (not the game shell). Dominant white/light page OK; two text links with Safari using secondary green link color `#2F7A4B`. No auto-redirect.

## Pixel-Art CSS Utilities

Declare in `src/index.css`:

```css
.pixelated {
  image-rendering: pixelated;
  image-rendering: crisp-edges;
}

.pixel-border {
  border: 4px solid var(--color-secondary);
  border-radius: 4px; /* not rounded-full */
  box-shadow: 4px 4px 0 #1A3324; /* hard pixel offset, not blur glow */
}

.touch-target {
  min-width: 48px;
  min-height: 48px;
}
```

**Nearest-neighbor image rule:** any `<img>` that will later show PokéAPI sprites or tiles must include `.pixelated` (or equivalent Tailwind arbitrary property). Scale with integer CSS sizes when possible (e.g. 64×64, 96×96). Phase 1 has no live sprites — still ship the utility and apply it to any decorative pixel asset.

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Bottom nav tap | Client-side route change; active state updates; no full reload |
| Start Safari | Navigates to `/game` |
| Keyboard | Tab order follows visual order; focus ring = accent 3px |
| Touch | `touch-action: manipulation` on buttons; no 300ms delay patterns |
| Motion (2–3 intentional) | (1) CTA press: 80ms scale to 0.96 then spring back; (2) active nav accent bar slides 150ms ease-out; (3) Home brand fades in 200ms on first mount. No continuous bounce loops, no glow pulses. |
| Reduced motion | Honor `prefers-reduced-motion: reduce` — skip fade/slide; instant state change |

## Accessibility

- Every nav item: icon **plus** visible text label (14px Label).
- Icon SVGs: `aria-hidden="true"` when adjacent text exists; buttons have accessible names matching labels.
- Contrast: text primary `#1A3324` on `#E3F2C9` and text-on-secondary `#F5FBEF` on `#2F7A4B` must meet WCAG AA for body/UI text.
- Destructive flow always requires confirmation dialog before Erase Progress (even if persist is stubbed).
