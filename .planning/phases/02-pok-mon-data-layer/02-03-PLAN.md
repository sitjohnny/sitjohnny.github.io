**As a** player, **I want to** prefetch Gen 1 Pokémon data once into a versioned local cache behind a Boot screen, **so that** gameplay never touches the network.

Purpose: Vertical slice for recoverability and gating — kid can retry without reload; Game stays packed until ready; warm starts feel instant.
Output: Finished BootScreen states, GameScreen gate, App bootstrap polish; BootScreen + GameScreen tests green.
</objective>
