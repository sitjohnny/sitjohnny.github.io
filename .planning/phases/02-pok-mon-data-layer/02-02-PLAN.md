## Phase Goal

**As a** player, **I want to** prefetch Gen 1 Pokémon data once into a versioned local cache behind a Boot screen, **so that** gameplay never touches the network.

<objective>
Ship the vertical happy path: typed Gen 1 prefetch + versioned namespaced cache + synchronous getPokemon, wired through a Boot route that shows progress (D-01, D-04) so a cold open fills the cache without gameplay network calls (DATA-01, DATA-02, DATA-04, partial BOOT-04).

Purpose: First user-visible slice — cold start Boot progress → ready memory/localStorage cache.
Output: pokeapi keys/client/cache, PokemonDto types, usePokemonCache, BootScreen loading path, App boot route + sync hydrate entry.
</objective>
